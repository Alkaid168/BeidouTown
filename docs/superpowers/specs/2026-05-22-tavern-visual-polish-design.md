# 酒馆聊天室视觉精修设计

**目标**

在不改动现有核心交互逻辑的前提下，把 tavern 页面从“已经能用”提升到“更有酒馆味道、更统一、更耐看”的完成态。重点只做视觉精修：消息气泡、头像配色、hover 元信息、输入区和提示窗的气质统一。

## 范围

本次精修只覆盖 tavern 页面视觉表现，不涉及新的行为需求。

包含：

1. 消息气泡质感重做
2. 头像配色方案收敛
3. hover 元信息样式精修
4. 输入区和长文本层视觉统一
5. 提示窗视觉统一
6. 删除态消息风格统一

不包含：

- 新的交互逻辑
- 回复、贴纸、图片、引用消息
- 消息结构变更
- 后端接口或数据模型变更
- 首页结构调整

## 方向选择

用户已确认本轮采用 **B：暖烛酒馆感**。

这意味着视觉基调从偏冷玻璃感，切换为：

- 偏暖的烛光色温
- 更像羊皮纸/酒馆便笺的半透明气泡
- 更接近木头、旧铜、灯火，而不是科技感霓虹
- 整体仍需保持清晰、干净、克制，不能做得脏乱或过度复古

## 设计原则

- **保留结构，重做气质**：不碰已稳定的交互骨架，只换视觉语言。
- **暖而不糊**：可以更暖，但不能因为泛黄或泛橙导致可读性下降。
- **局部发光，不做炫光污染**：hover 效果要精致，不能像游戏 UI 特效。
- **同一页面只讲一种审美语言**：消息、输入区、提示窗、按钮都要像同一家店里的东西。

## 视觉方案

### 1. 消息气泡

当前气泡已经具备基本形态，但仍偏“通用磨砂面板”。本轮改成更像酒馆里的暖色便笺：

- 背景从冷白透明改成偏暖的半透明棕灰 / 琥珀灰
- 边框从普通浅白，改成更接近旧铜色 / 烛光反射色
- 阴影从黑色块感，改成更柔和、更低位置的烛光式阴影
- 气泡尖角保留，但边缘颜色与主气泡统一，不能像单独贴上去的三角片
- 正常状态更轻，hover 状态只提升一点点亮度、边缘高光和细阴影，不改变大小和位置

目标：一眼看上去像“酒馆里的对话卡片”，不是系统面板。

### 2. 头像配色

当前头像颜色逻辑是稳定的，但色域太自由，容易出现不够酒馆的颜色。

本轮保留“根据 nickname 稳定映射”的机制，但把颜色限制进一组更适合 tavern 的暖暗色池，例如：

- 深茶棕
- 橄榄绿
- 酒红棕
- 烟紫灰
- 旧铜金

要求：

- 同一用户依然稳定同色
- 不出现过亮的荧光色
- 头像与背景要分得开，但不要太跳
- 文字保持白色或暖白色，保证识别度

### 3. Hover 元信息

hover 时显示 nickname + time 的结构保留，但样式要从“技术信息条”改成“酒馆铭牌”：

- 背景更暖、更深
- 轮廓更细，像薄金属边或旧漆标签
- 字距收一点，不要太像系统时间戳
- 保持绝对定位浮在上方，不推动正文
- 可增加轻微淡入，不允许位移跳动

目标：存在感更低，但更精致。

### 4. 输入区

输入区现在功能完整，但视觉上仍偏通用组件。精修目标是让它像“吧台前的书写槽”：

- 底板更像暗木/旧铜托盘
- 输入框内层与外层要有层次，不只是一个简单透明盒子
- 展开按钮和发送按钮需要更像一套酒馆工具，而不是普通 icon button
- 未展开时的输入槽要更薄更稳
- 长文本层展开后应像一块从桌面向上掀起的书写板

### 5. 提示窗

“先喝口茶，稍后再说。”已经改成小浮窗，本轮继续统一它的风格：

- 和 hover 元信息、输入区用同一套暖色体系
- 更像“酒馆里的小提示牌”
- 动画只保留淡入与渐隐，不做弹跳
- 出现位置继续保持不挡住主要阅读区

### 6. 删除态消息

删除态不能比正常消息更抢眼。

精修方向：

- 仍然保留气泡骨架
- 降低对比度
- 用更柔和的暖灰文本
- 让它看起来像“纸上字迹淡去了”，而不是系统报错框

## 建议实现层次

本轮实现建议拆成两层：

### 第一层：消息系统统一

涉及：

- `tavern-avatar.tsx`
- `tavern-message-item.tsx`
- `markdown-message.tsx`（必要时只调颜色和字距，不改语义结构）

完成后应解决：

- 气泡更像暖烛酒馆便笺
- 头像不再有跳色感
- hover 元信息和删除态更统一

### 第二层：输入系统统一

涉及：

- `tavern-client.tsx`
- `globals.css`（如需局部动画或阴影 keyframes）

完成后应解决：

- 输入区像 tavern 自己的一部分
- 展开层与底部槽风格统一
- 提示窗不突兀

## 受影响文件

预计主要是：

- `src/components/tavern/tavern-avatar.tsx`
- `src/components/tavern/tavern-message-item.tsx`
- `src/components/tavern/tavern-client.tsx`
- `src/components/tavern/markdown-message.tsx`
- `src/app/globals.css`（如果需要少量动画或通用视觉 token）

大概率不需要新增路由、API 或数据库文件。

## 测试策略

因为本轮不改核心行为，测试重点不是新增复杂逻辑，而是保证现有交互不被视觉修改破坏。

至少保证以下测试仍然通过：

1. 发送入口仍存在
2. Enter / Ctrl+Enter 行为不变
3. 右键菜单仍可打开与关闭
4. 消息区仍独立滚动
5. 自动贴底逻辑仍在
6. guest 状态仍可进入登录页

可以新增少量样式级断言，例如：

- avatar 使用新的尺寸或 class
- hover 元信息层仍为绝对定位
- toast 仍存在并可渲染

但不要为了视觉微调堆过多脆弱测试。

## 手动验收标准

1. 打开 `/tavern`，整体观感明显更暖、更像真实酒馆
2. 气泡不再像通用玻璃面板，而更像暖色便笺
3. 头像颜色看起来属于同一套色盘
4. hover 元信息更轻、更美观、位置稳定
5. 输入区和长文本板风格统一
6. 提示窗不再像系统报错，而像酒馆提示
7. 所有既有交互仍正常：发送、自动贴底、右键菜单、长文本展开、登录跳转
