# 北斗镇

北斗镇是一个神秘夜色气质的网页小镇。MVP 计划包含：

- 小酒馆：单公共聊天室。
- 树洞邮局：投递心情和思考，默认匿名。
- 寺庙：塔罗牌占卜与 AI 解读。
- 居民系统：注册、登录、昵称、头像和基础权限。
